# skills/

Библиотека generic-файлов skill/промптов для AI-агентов (Claude Code и аналогичные инструменты) разработки — **не относится к приложению Perricheno и не является частью его рантайма**. Ни один из этих файлов не импортируется и не читается кодом сайта/сервисов (в отличие от [`../r/`](../r/), которая реально подключается в промпт агента через `src/lib/agent/knowledge/loader.ts`).

Содержимое — общие инструкции по темам разработки, не специфичные для этого проекта: `architecture/` (архитектурный ревью, C4-диаграммы), `auditor/` (код-ревью, security-аудит), `backend_platforms/` (Clerk, Convex, Firebase, Neon, Supabase), `database/`, `devops/` (Terraform, GitOps, Grafana), `github/`, `product_performance/`, `react_tsx/`, `security/`, `ui_ux/`.

Хранится в репозитории, по всей видимости, как вспомогательный инструментарий для AI-ассистентов, работающих над кодовой базой (в духе тех же принципов, что и сам процесс этого аудита), а не как код или конфигурация продукта.
