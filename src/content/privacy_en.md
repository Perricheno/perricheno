# 1. INFORMATION COLLECTION
Perricheno collects minimum data necessary for platform functionality. This includes your Telegram ID (for login purposes), chat logs (to provide context to conversational LLMs), and session persistence data (including document drafts, R-visualizations, and task queues).

# 2. AI DATA PROCESSING
Information you provide in prompts and documents generated by the platform may be processed by third-party AI models (e.g., OpenAI/Anthropic/Google). We encourage users not to provide highly sensitive personal or corporate data within the prompts, as these are processed through encrypted but external API nodes.

# 3. DATA RETENTION
Your session data is stored in our encrypted database for as long as you maintain an account or until you delete the specific session via the dashboard controls. You may delete all your session data and associated visualizations at any time.

# 4. SECURITY PROTOCOLS
We use standard database encryption at rest and secure API communication (HTTPS) to protect your data. Internal access to the R-Compiler execution environment is restricted to automated scripts and the system administrator.

# 5. USER RIGHTS (GDPR / CCPA)
Under international data protection regulations, you have the right to access, rectify, or erase your data. Please contact Perricheno Inc. support if you require a full data export or account closure.

# 6. SUB-PROCESSORS
Perricheno Inc. utilizes standard cloud infrastructure (e.g., Vercel, Railway, OpenAI) to host services and perform AI inference. Data shared with these sub-processors is strictly restricted for the use case at hand.
