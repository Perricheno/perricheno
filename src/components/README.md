# src/components/

## Что тут лежит

Переиспользуемые React-клиентские компоненты (`"use client"`), не привязанные к конкретному Next.js-роуту в `src/app/`. В основном относятся к "старому"/маркетинговому и вспомогательному UI сайта (домашняя страница, чат-виджет, боковая панель, модалки логина/настроек), а не к самим страницам агента/спейсов, которые лежат прямо в `src/app/[locale]/...`.

## Зачем существует

Next.js App Router допускает совмещать компоненты и роуты в `src/app/`, но здесь общие для нескольких страниц или самодостаточные UI-блоки (навигация, тосты, контекст админа) вынесены в `src/components/`, чтобы их можно было импортировать из разных мест `src/app/[locale]/**` без циклических путей.

## Как использовать

Импортируются напрямую: `import { MinimalSidebar } from "@/components/MinimalSidebar"` и т.п. Компонент верхнего уровня для главной страницы — `HomePage.tsx`, который сам подключает секции из `home/`.

## Файлы верхнего уровня

| Файл | Строк | Что делает |
|---|---|---|
| `AdminContext.tsx` | 115 | React Context (`AdminProvider`/`useAdmin`) с состоянием текущего пользователя (`User \| null`), флагами `isEditing`/`showLogin` и методами `login`/`logout`/`deleteAccount`. Центральный источник данных об авторизации для клиентских компонентов. |
| `ChatPage.tsx` | 400 | Полноэкранный UI чата (n8n-webhook based, не agent-конвейер): ввод текста/файлов/аудио, история тредов, настройки через `ChatSettingsModal`. Крупный компонент — см. `docs/REVIEW.md`. |
| `ChatSettingsModal.tsx` | 185 | Модалка настроек чата — редактирует `ChatSettings` (webhook URL, модель, temperature, maxTokens) через server actions `getSettings`/`saveSettings` из `src/app/actions.ts`; видна только при `isEditing` (админ-режим). |
| `CodeLab.tsx` | 237 | UI редактора кода (`CodeMirror`) с выбором Python/R и панелью вывода — судя по заглушке в `output`, изолированный демо/лабораторный интерфейс, не проверялось подключение к реальному compile-API. |
| `DashboardPage.tsx` | 124 | Страница встраивания внешних дашбордов (PowerBI и т.п.) через `<iframe>` по URL, который можно добавлять в режиме редактирования администратора. |
| `HomePage.tsx` | 84 | Оркестратор секций главной страницы — только вёрстка-контейнер и подключение секций из `home/` (Hero, Features, Pricing, FAQ и т.д.) плюс состояние переключателя годовой/месячной оплаты. Сильно уменьшен по сравнению со старым `AUDIT.md` (было 769 строк). |
| `LoginModal.tsx` | 338 | Модалка входа через Telegram: либо Telegram Login Widget, либо deep-link/QR на бота с поллингом статуса авторизации; также содержит удаление аккаунта (`deleteAccount`, с подтверждением). |
| `MinimalSidebar.tsx` | 548 | Главная боковая навигация приложения (агент, R Studio, PDF, citations, code, dashboard, настройки, биллинг), с анимациями сворачивания/разворачивания (`framer-motion`) и переключением языка. Крупнейший компонент в проекте — см. `../../docs/REVIEW.md`, раздел «Можно отложить». |
| `ProjectSection.tsx` | 459 | Блок управления проектами/портфолио (карточки проектов + встроенные дашборды) с CRUD в режиме администратора. Второй по размеру компонент — см. `../../docs/REVIEW.md`. |
| `ProjectsPage.tsx` | 123 | Отдельная полноэкранная страница списка проектов (похожа по данным на `ProjectSection.tsx`, но в виде самостоятельной страницы, а не встраиваемой секции). |
| `ThemeToggle.tsx` | 25 | Кнопка переключения светлой/тёмной темы поверх `next-themes` (`useTheme`), с защитой от гидратационного мисматча через `mounted`. |
| `ToastContext.tsx` | 66 | React Context для всплывающих уведомлений (`success`/`error`/`info`) — `ToastProvider`/`useToast()`. |
| `theme-provider.tsx` | 9 | Тонкая обёртка вокруг `next-themes`' `ThemeProvider`. |

## Подпапка `home/` (секции главной страницы)

| Файл | Что делает |
|---|---|
| `HeroSection.tsx` | Первый экран (заголовок, CTA, анимация появления). |
| `FeaturesSection.tsx` | Секция возможностей продукта. |
| `HowItWorksSection.tsx` | Секция "как это работает" (шаги, `STEPS` из `constants.ts`). |
| `PricingSection.tsx` | Секция тарифов — держит состояние переключателя годовой/месячной оплаты и валюты, рендерит `PricingCard` на каждый план из `PLANS`. |
| `PricingCard.tsx` | Одна карточка тарифа с фичами и CTA. |
| `SocialProofSection.tsx` | Блок с "доказательствами" (LaTeX+PDF, реальные цитаты, R+Python) — статические маркетинговые заявления. |
| `LogoMarquee.tsx` | Бегущая строка логотипов с зацикленной анимацией. |
| `FaqSection.tsx` | Секция FAQ (`FAQ` из `constants.ts`). |
| `FinalCtaSection.tsx` | Финальный призыв к действию + подвал сайта. |
| `FloatingOrbs.tsx` | Декоративные анимированные "шары"-подсветка для CTA-секции. |
| `RotatingBorderWrapper.tsx` | Вращающаяся conic-gradient рамка вокруг Pro-карточки тарифа (через `requestAnimationFrame`). |
| `constants.ts` | Статические данные секций: `PLANS` (тарифы), `STEPS`, `FAQ`, `LOGOS`, `FEATURES`. |
| `primitives.tsx` | Переиспользуемые примитивы: `MagneticButton` (кнопка со spring-физикой, следующая за курсором), `NavLink`, `SectionLabel`, `FaqItem`. |

| Файл | Что делает |
|---|---|

## Известные ограничения / технический долг

- Три компонента в топе списка "крупных файлов" находятся именно здесь: `MinimalSidebar.tsx` (548 строк), `ProjectSection.tsx` (459), `ChatPage.tsx` (400) — см. [`../../docs/REVIEW.md`](../../docs/REVIEW.md), раздел «Можно отложить».
- Отдельно не проверялось, используются ли `CodeLab.tsx`, `DashboardPage.tsx`, `ProjectsPage.tsx`/`ProjectSection.tsx` активно в проде или это более ранние/экспериментальные экраны — требует уточнения у владельца.
