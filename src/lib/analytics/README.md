# src/lib/analytics/

## Что тут лежит

Конвейер генерации графиков/визуализаций из пользовательских данных (CSV/XLSX/JSON) — отдельный продукт от agent-конвейера (хотя переиспользует его LLM-обёртку `llm.ts` и внешние R/Python-компиляторы). Плюс менеджер временных файлов, через который данные попадают на диск для этих компиляторов.

## Зачем существует

Обслуживает раздел "R Studio" / генерацию аналитики (`/api/agent/data-analytics`, `/api/agent/analytics/generate`) — пользователь загружает файл с реальными данными, а конвейер строит серию графиков (bar/heatmap/PCA/ARIMA и ещё ~35 других типов) на основе реальных, а не синтетических данных.

## Как использовать

Не запускается отдельно — `runAnalyticsPipeline()` из [`pipeline/index.ts`](pipeline/README.md) импортируется из соответствующего API-роута. `saveFilesToDisk()`/`startCleanupTask()` из `fileManager.ts` используются как agent-конвейером (`stage2_6_r_figures.ts`), так и analytics-конвейером — это общая точка записи файлов для внешних R/Python-микросервисов.

## Ключевые файлы и подпапки

| Путь | Что в нём |
|---|---|
| [`pipeline/`](pipeline/README.md) | 3 стадии: верификация данных → планирование графиков → генерация кода. Подробный README внутри. |
| `fileManager.ts` | `saveFilesToDisk()` — сохраняет содержимое `AgentUpload` (из БД или скачивает из MinIO через `downloadTextFromStorage`) в `/tmp/analytics-data/` под уникальным именем, чтобы R/Python-компиляторы (отдельные контейнеры) могли прочитать файл с общего volume. `startCleanupTask()` (вызывается из `../server-init.ts`) — периодически удаляет файлы старше 24 часов из этой директории. |

## Известные ограничения / технический долг

- `cleanupOldFiles()` (в `fileManager.ts`) падает с `ENOENT`, если директория `/tmp/analytics-data` (на Windows — `C:\tmp\analytics-data`) не существует при старте — ошибка перехватывается и не роняет процесс, но замусоривает логи при каждом запуске/интервале на локальной машине без Docker-volume; функция не создаёт директорию сама перед `readdir`. См. [`../../../docs/REVIEW.md`](../../../docs/REVIEW.md), раздел «Можно отложить».
- Библиотека `xlsx` (SheetJS), которой пользуется `stage1_verify_data.ts` при разборе загруженных файлов, имеет известные непропатченные уязвимости (Prototype Pollution, ReDoS) — см. [`../../../docs/REVIEW.md`](../../../docs/REVIEW.md), пункт 4.
