# Правила работы с языками в LaTeX (KAZ, RUS, ENG)

Наш компилятор поддерживает автоматическое переключение на XeLaTeX. Для корректного отображения символов и использования системных шрифтов следуй этим правилам.

## 1. Казахский язык (KAZ)
**Движок:** Только XeLaTeX (автоматически включается при использовании `fontspec`).
**Обязательные пакеты:**
```latex
\usepackage{fontspec}
\usepackage[kazakh]{babel}
\setmainfont{Inter} % Использовать Inter или PT Serif для академического стиля
```
**Шрифты с поддержкой казахского:** `Inter`, `Montserrat`, `PT Serif`, `PT Sans`, `Roboto`.

## 2. Русский язык (RUS)
**Рекомендуемый движок:** XeLaTeX.
**Обязательные пакеты:**
```latex
\usepackage{fontspec}
\usepackage[russian]{babel}
\setmainfont{PT Serif}
```

## 3. Английский язык (ENG)
Можно использовать стандартные настройки или XeLaTeX для единообразия шрифтов.
```latex
\usepackage{fontspec}
\setmainfont{Inter}
```

## Доступные системные шрифты (Pre-installed)
- **Inter**: Универсальный, современный (рекомендуется для отчетов).
- **PT Serif**: Классический с засечками (лучшая замена Times New Roman).
- **PT Sans**: Современный без засечек.
- **Montserrat**: Геометрический, хорош для заголовков.
- **Roboto**: Чистый, читабельный.

> **Важно**: Всегда используй `\usepackage{fontspec}`, когда язык документа — Казахский. Это гарантирует, что компилятор переключится в режим `-pdfxe` и правильно отобразит специфические буквы (ә, і, ң, ғ, ү, ұ, қ, ө, һ).
