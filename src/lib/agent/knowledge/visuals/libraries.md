# Доступные библиотеки для визуализации

## R (Pre-installed)

Эти пакеты уже установлены в системе и готовы к `library()`:

- **Базовый стек**: `ggplot2`, `dplyr`, `tidyr`, `readr`, `tibble`, `stringr`, `forcats`, `lubridate`
- **Темы и стили**: `ggthemes`, `hrbrthemes`, `ggsci`, `viridis`, `RColorBrewer`, `scales`
- **Специальные графики**: `plotly`, `corrplot`, `pheatmap`, `treemap`, `igraph`, `fmsb`, `waffle`, `waterfalls`, `wordcloud`
- **Композиция и шрифты**: `patchwork`, `gridExtra`, `ggrepel`, `ggridges`, `showtext`, `Cairo`, `svglite`
- **3D**: `plot3D`, `scatterplot3d`

## Python (Pre-installed)

- **Анализ и расчеты**: `pandas`, `numpy`, `scipy`
- **Визуализация**: `matplotlib`, `seaborn`, `plotly`
- **Шрифты**: `matplotlib.font_manager`

## Системные шрифты (для XeLaTeX)
Эти шрифты поддерживают Казахский, Русский и Английский языки:
- **Serif (с засечками)**: `PT Serif` (академический стандарт), `Liberation Serif`
- **Sans (без засечек)**: `Inter` (рекомендуется), `Montserrat`, `Roboto`, `PT Sans`, `Liberation Sans`
- **Mono (моноширинный)**: `Cousine`, `Liberation Mono`

> **Инструкция**: Используй только эти библиотеки и шрифты. Если тебе нужен специфический график, поищи подходящий пакет в списке выше. Не пытайся использовать библиотеки, которых нет в списке.
