# src/lib/agent/

## Что тут лежит

Конвейер генерации научного LaTeX-отчёта — основной продукт приложения. Пользователь (через веб или Telegram-бота) задаёт тему/настройки, а этот код проходит 6 стадий: план → извлечение ссылок → верификация/обогащение/визуалы/данные → черновик секций → сборка LaTeX → валидация/компиляция с авторемонтом.

## Зачем существует

Вызывается из `POST /api/agent/generate` как фоновая (fire-and-forget) задача: HTTP-роут отвечает сразу, а сам конвейер пишет прогресс в поле `agent_sessions.stage_json`, которое UI опрашивает поллингом. Вся логика "как из промпта получить готовый .tex" сосредоточена здесь, а не в роуте.

## Как использовать

Не запускается отдельно — импортируется из `src/app/api/agent/generate/route.ts` через `runPipeline()` (`pipeline/index.ts`). Подробное построчное описание бизнес-правил каждой стадии — [`../../../docs/business_logic.md`](../../../docs/business_logic.md), раздел 5 («Конвейер генерации отчёта»).

## Ключевые файлы и подпапки

| Путь | Что в нём |
|---|---|
| [`pipeline/`](pipeline/README.md) | Сами 6 стадий конвейера + оркестратор + обёртка над LLM. Подробный README внутри. |
| [`templates/`](templates/README.md) | 5 preset-преамбул LaTeX-документа (plain/academic/ieee/elegant/minimal). |
| [`knowledge/`](knowledge/README.md) | Markdown-база знаний (правила LaTeX-языков, стандарты кода для визуализаций), которая подмешивается в системные промпты LLM через `knowledge/loader.ts`. |
| `pdfIngest.ts` (72 строки) | Клиент к внешнему микросервису `pdf-extractor` (переменная `PDF_EXTRACTOR_URL`, дефолт `http://pdf-extractor:8080`). Отправляет PDF на `/extract`, получает обратно текст + встроенные изображения (с капом 2 МБ на картинку) + OCR-флаг. Никакого парсинга PDF на клиенте или в Node — всё делает внешний сервис. |
| `stages.ts` (238 строк) | Общие чистые (без сети/БД) утилиты для всех стадий: `withRetry()` (retry с экспоненциальным backoff), `concurrentMap()` (bounded-concurrency обработка массива), плюс, судя по использованию в других файлах, языковые таблицы (`BABEL_LANG_MAP`) и хелперы нормализации LaTeX (`normalizeLatexText`, `ensureRussianPreamble`, `findUnresolvedCitations`, `checkLatexStructure`). |

## Известные ограничения / технический долг

- Специфичных находок по этой директории в `docs/REVIEW.md` нет — общие пункты (281 использование `any` по `src/`, отсутствие тестов на критичную логику) применимы и здесь, отдельно не разбирались.
- Точный состав экспортов `stages.ts` за пределами `withRetry`/`concurrentMap` не проверялся построчно на 100% — при необходимости смотреть файл напрямую.
