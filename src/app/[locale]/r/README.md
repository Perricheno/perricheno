# src/app/[locale]/r/

## Что тут лежит

UI R Studio — отдельного от Agent продукта для быстрой генерации статистических графиков через R по загруженным данным или промпту. Сессии здесь (`RSession`) лёгкие: только план + результаты (`results_json`), без стадийного пайплайна и без итогового LaTeX-документа — см. [`docs/glossary.md`](../../../../docs/glossary.md), запись «RSession (R Studio)».

## Зачем существует

Позволяет получить набор графиков (violin/density/scatter/heatmap и т.д. — полный каталог типов в `charts.ts`) без запуска полноценной генерации отчёта в `/agent`. Генерация — через `POST /api/r/generate`, загрузка данных — `POST /api/r/upload`, контракт — [`docs/api_reference.md`](../../../../docs/api_reference.md), раздел 3.

## Ключевые файлы

| Файл | Что показывает |
|---|---|
| `page.tsx` | Стартовый экран `/r`: промпт + загрузка файла с данными, выбор/предложение типов графиков, запуск генерации. |
| `RSidebar.tsx` | Сайдбар со списком R-сессий пользователя (аналог `AgentSidebar`, но для `RSession`). |
| `charts.ts` | Статический каталог типов графиков (`CHARTS`) — id, имя, категория/тег, превью — источник данных для `ChartGallery`/`ChartCard`/`RChartSheet`. |
| `ChartGallery.tsx` | Сетка карточек доступных типов графиков с отметкой "предложено AI" (`suggestedCharts`) и обоснованием выбора. |
| `ChartCard.tsx` | Одна карточка типа графика в галерее/шите — превью, состояние выбран/не выбран. |
| `RChartSheet.tsx` | Выезжающий снизу шит (bottom sheet) с полным каталогом графиков, с фильтром по тегам. |
| `MultiChartCard.tsx` | Карточка уже сгенерированного графика в результатах — превью изображения, повтор генерации конкретного графика, копирование R-кода, полноэкранный просмотр. |
| `[sessionId]/page.tsx` | Server-компонент: проверяет владение сессией через `getRSession(sessionId, userId)`, рендерит `RSessionClient`. |
| `[sessionId]/RSessionClient.tsx` | Экран конкретной R-сессии: список сгенерированных графиков, чат для уточнения/добавления графиков, экспорт. |

## Известные ограничения

- В отличие от `agent/` и `space/`, здесь нет отдельного README на подпапку `[sessionId]` — она достаточно проста (один клиентский компонент), но не проверялось на предмет собственного технического долга построчно.
- Уязвимость в парсере `xlsx` (SheetJS) — Prototype Pollution / ReDoS без официального патча — напрямую применима к `/api/r/upload`, который разбирает загруженные пользователем файлы этой библиотекой: [`docs/REVIEW.md`](../../../../docs/REVIEW.md), пункт 4.
- Ни одного теста на эту логику.
