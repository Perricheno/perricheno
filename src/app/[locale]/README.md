# src/app/[locale]/

## Что тут лежит

Все страницы (page-роуты) веб-панели — Next.js App Router с динамическим сегментом `[locale]` для локализации через `next-intl`. Локали заданы в [`src/i18n/routing.ts`](../../i18n/routing.ts): `ru` (по умолчанию), `en`, `kz`. `src/app/actions.ts` (уровнем выше, вне `[locale]`) и API (`src/app/api/`) в эту локализацию не завёрнуты.

## Зачем существует / как устроена локализация

- `src/middleware.ts` перехватывает все запросы (кроме `api`, статики), матчит `/(ru|en|kz)/:path*`, и через `next-intl/middleware` определяет/подставляет локаль; голый путь без префикса редиректится на дефолтную локаль.
- `[locale]/layout.tsx` — корневой layout всей веб-панели: оборачивает страницы в `NextIntlClientProvider` (сообщения только текущей локали, не все три сразу), `ThemeProvider` (light, без auto-detect системной темы), `AdminProvider`/`ToastProvider` (глобальные React-контексты), и рендерит постоянный `MinimalSidebar`.
- Переводы подключаются per-page через `useTranslations("namespace")` (клиентские компоненты) или `getTranslations()` (серверные) — сами JSON/строки переводов не входят в область этого README.

## Разделы

Ниже — по одной строке на каждый верхнеуровневый путь, проверено чтением реального `page.tsx`/`route.ts`, а не по названию папки. Для крупных разделов со своей внутренней логикой — отдельный README (ссылка).

| Путь | Что это по факту |
|---|---|
| `page.tsx` | Главная (`/`) — тонкая обёртка, рендерит `@/components/HomePage` (лендинг, не в этой директории). |
| [`agent/`](agent/README.md) | Ядро продукта — генератор научных LaTeX-отчётов, чат по документу, Scholar-поиск, аналитика данных. Подробный README внутри. |
| [`space/`](space/README.md) | Совместный LaTeX-редактор проектов (Overleaf-подобный) с реал-тайм совместным редактированием через Yjs. Подробный README внутри. |
| [`r/`](r/README.md) | R Studio — отдельные от Agent лёгкие сессии генерации статистических графиков через R. Подробный README внутри. |
| [`tikz/`](tikz/README.md) | Генератор LaTeX/TikZ-диаграмм (концепт-карты, схемы процессов и т.д.) из текстового промпта. Подробный README внутри. |
| [`dashboard/`](dashboard/README.md) | Не пользовательский раздел — скрытая суперадмин-панель (`/dashboard`, "Project Overseer"), доступ хардкодом одного `telegram_id`. Подробный README внутри. |
| [`citations/`](citations/README.md) | Менеджер библиографии: поиск публикаций + AI Scholar-поиск + личная библиотека цитат. Один большой `page.tsx` (920 строк), README внутри. |
| [`settings/`](settings/README.md) | Личный кабинет пользователя (профиль, биллинг-история) — и, если `isAdmin`, встроенная в ту же страницу мини-панель админа (промокоды, поиск пользователей). Один большой `page.tsx` (538 строк), README внутри. |
| [`billings/`](billings/README.md) | Публичная страница тарифов + оформление подписки/чекаут. Один большой `page.tsx` (563 строки), README внутри. |
| `chat/` | Отдельный от Agent универсальный чат-виджет (`/chat`) — умеет слать сообщения на кастомный внешний webhook (настраивается в `ChatSettingsModal`), с фоллбэком на `/api/webhook-proxy`; хранит историю в IndexedDB + `/api/chat/history`. |
| `pdf/` | PDF-тулкит (`/pdf`) — конвертация/слияние/защита/OCR и т.д., UI-обёртка над внешним Stirling PDF API (см. `/api/pdf-proxy` и `docs/integrations.md`). Один файл на ~1000 строк, отдельный README не заведён (нет собственных подкомпонентов/подпапок). |
| `tasks/` | Текстовые напоминания пользователя — создание через LLM-парсинг свободного текста (`/api/tasks/parse`), список/статус через `/api/tasks`. |
| `code/` | Тривиальная обёртка (9 строк) — рендерит `@/components/CodeLab`, вся логика живёт вне `[locale]`. |
| `callback/route.ts` | **Не page, а API route** внутри `[locale]` (публичный путь `/{locale}/callback`) — второй, дублирующий обработчик вебхука CryptoCloud. См. известные ограничения ниже. |
| `privacy/`, `terms/` | Статичные страницы (юридические тексты) — читают markdown-файлы из `src/content/{privacy,terms}_{ru,en}.md` и рендерят через `react-markdown`. Собственной логики, кроме выбора языка, нет. |
| `failed-payment/`, `successful-payment/` | Тривиальные страницы-результаты редиректа с платёжного шлюза (иконка + текст + кнопка "назад"), без запросов к API. |
| `under-construction/` | Стилизованная страница-заглушка "сайт/раздел в разработке" с анимированным псевдо-логом компиляции; не проверялось, откуда на неё реально ведут ссылки. |

## Известные ограничения

- `callback/route.ts` — второй обработчик CryptoCloud-вебхука, у которого проверка подписи **не блокирует** запрос при несовпадении (закомментированный `return` вместо реального отказа) — подробный разбор и вопрос владельцу (используется ли этот URL вообще) уже в [`docs/REVIEW.md`](../../../docs/REVIEW.md), пункт 1, и [`docs/integrations.md`](../../../docs/integrations.md), раздел 2.
- `pdf/page.tsx`, `chat/page.tsx`, `tasks/page.tsx` — крупные (200–1000 строк) монолитные клиентские компоненты без разбиения на подкомпоненты; отдельный README для них не заведён по указанию задачи (единственный файл, не считается самостоятельной структурой), при необходимости смотреть код напрямую.
