# src/app/[locale]/agent/

## Что тут лежит

UI генератора научных документов (LaTeX-отчёт/диплом/лабораторная/литобзор и т.д.) — главный продукт приложения. `page.tsx` — экран создания новой сессии (выбор типа документа, настроек, вложений); после отправки промпта создаётся `AgentSession` (модель в Prisma, см. [`docs/data_model.md`](../../../../docs/data_model.md)) и пользователь попадает на один из специализированных под-роутов ниже, в зависимости от `doc_type` сессии.

## Зачем существует

Отделяет UI (этот каталог) от самого конвейера генерации (`src/lib/agent/**`, вызывается через `POST /api/agent/generate` и другие роуты `api/agent/*` — контракт в [`docs/api_reference.md`](../../../../docs/api_reference.md), раздел 2). Разбиение на под-роуты по `doc_type` (`chat`, `data_analytics`, `literature_search`, и "всё остальное" → research) позволяет каждому типу сессии иметь свой набор виджетов, не раздувая один компонент.

## Ключевые файлы верхнего уровня

| Файл | Что показывает пользователю |
|---|---|
| `page.tsx` | Стартовый экран `/agent`: форма создания новой сессии — тип документа, стиль, объём, язык, вложения, список последних сессий. |
| `AgentBillingModal.tsx` | Модалка биллинга/лимитов агента: сколько символов/отчётов/визуалов доступно на тарифе, история использования. |
| `AgentSettingsPanel.tsx` | Разворачиваемая панель настроек генерации (шаблон, стиль, объём, колонки, язык, использование референсов) — используется и на стартовом экране, и внутри сессии. |
| `AgentSidebar.tsx` | Выезжающий сайдбар со списком сессий пользователя (выбор/удаление/шаринг), общий для всех под-роутов сессии. |
| `AgentVisualizations.tsx` | Панель визуализаций внутри сессии — превью сгенерированных графиков (R/Python), запуск редактирования кода, добавление визуала в отчёт. |
| `CodeEditorModal.tsx` | Модалка редактирования кода визуализации (CodeMirror, Python/R) с перекомпиляцией превью на лету. |
| `TemplatePicker.tsx` | Выбор преамбулы LaTeX-документа (миниатюры preview) — соответствует пресетам из `src/lib/agent/templates/`. |
| `types.ts` | Общие типы UI-слоя: `DocType`, `Style`, `Language`, `AgentSettings`, `ChatMessage`, `CodeImage`, `AgentSession` и т.п. — используются всеми файлами ниже. |

## Подпапки (сессия по `doc_type`)

| Подпапка | Что показывает | `doc_type`, для которого предназначена |
|---|---|---|
| `[sessionId]/` | **Не полноценная страница, а редиректор**: `page.tsx` смотрит `doc_type` сессии и перенаправляет на нужный под-роут ниже (`chat`→`/agent/chat/:id`, `data_analytics`→`/agent/analytics/:id`, `literature_search`→`/citations`, всё остальное→`/agent/research/:id`). См. известные ограничения — собственный `AgentSessionClient.tsx` в этой папке нигде не рендерится. |
| `research/[sessionId]/` | Основной экран работы над отчётом/дипломом/лабораторной и т.п. — чат с агентом, прогресс стадий генерации, превью PDF, вкладка визуализаций (`AgentVisualizations`). Обслуживает все `doc_type`, кроме `chat`/`data_analytics`/`literature_search`. |
| `analytics/[sessionId]/` | Аналог `research/`, но для `doc_type=data_analytics` — работа с загруженными данными и генерацией графиков вместо текстового документа. |
| `chat/[chatId]/` | Экран простого чата с агентом (`doc_type=chat`, без стадийного пайплайна генерации отчёта) — `ChatClient.tsx` + `MessageBubble.tsx`. |
| `scholar/[id]/` | Экран AI-поиска научных публикаций (`doc_type=literature_search`, `ScholarClient.tsx`) — используется через прямые переходы `router.push('/agent/scholar/:id')` из других клиентов, а не через редиректор `[sessionId]` (тот отправляет `literature_search` на `/citations`, см. известные ограничения). |
| `shared/[shareId]/` | Публичная read-only страница расшаренной сессии по `share_id` (`SharedSessionView.tsx`) — доступна без авторизации, генерируется через `POST /api/agent/sessions/[id]/share`. |

## Известные ограничения

- **Мёртвый код**: `agent/[sessionId]/AgentSessionClient.tsx` (753 строки) импортируется в `agent/[sessionId]/page.tsx`, но там ни разу не рендерится — функция страницы только делает `redirect(...)` во всех ветках. Это более ранняя версия компонента, вытесненная его копией в `research/[sessionId]/AgentSessionClient.tsx` (940 строк, реально используется) после того, как логику разнесли по под-роутам; не проверялось, безопасно ли просто удалить файл. Не зафиксировано в `docs/REVIEW.md` — новая находка этого README.
- Диспетчер `[sessionId]/page.tsx` отправляет `doc_type=literature_search` на `/citations`, а не на `/agent/scholar/[id]`, хотя маршрут `scholar/[id]` существует и реально используется (переходы на него идут напрямую из `AgentSidebar`/клиентов сессий, минуя диспетчер) — несогласованность, не проверялось, намеренная ли.
- `AgentSessionClient.tsx` в `[sessionId]/`, `research/[sessionId]/` и `analytics/[sessionId]/` — три похожих, но разошедшихся файла с одинаковым именем (563 строки diff между `[sessionId]` и `research` версиями); общей логики между ними не вынесено в переиспользуемый модуль.
- Специфичных находок по этому каталогу в `docs/REVIEW.md` нет за пределами общих пунктов (281 использование `any`, отсутствие тестов) — детали см. там.
