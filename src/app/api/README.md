# src/app/api/

## Что тут лежит

Все HTTP API Next.js App Router: 90 файлов `route.ts` (119 экспортированных обработчиков `GET`/`POST`/`PUT`/`PATCH`/`DELETE` — часть файлов отвечает на несколько методов), сгруппированные по функциональным разделам-подпапкам. Это единственный слой, который вызывают и веб-фронтенд (`src/app/[locale]/**`), и Telegram-бот (`telegram-bot/`, как отдельный HTTP-клиент, а не через прямой импорт кода).

## Зачем существует

Next.js App Router требует физического файла `route.ts` на каждый путь — структура папок здесь один в один совпадает со структурой URL (`src/app/api/agent/sessions/[id]/route.ts` → `/api/agent/sessions/:id`). Сама бизнес-логика (запросы к БД, вызовы LLM, лимиты) в большинстве роутов не живёт — она вынесена в `src/lib/**` и импортируется; роут обычно — это разбор запроса, авторизация и вызов функции из `lib`.

## Разделы

Полный контракт каждого эндпоинта (метод, авторизация, тело запроса/ответа, коды ошибок) — **[`docs/api_reference.md`](../../../docs/api_reference.md)**. Ниже — только список разделов, без пересказа.

| Раздел | Путь | Что внутри (1 строка) |
|---|---|---|
| Auth | `auth/*` (6 роутов) | Telegram Login Widget, сессионная JWT-кука, привязка/отвязка аккаунта, long-poll для бот-логина. |
| Agent | `agent/*` (22 роута) | Ядро продукта: генерация LaTeX-отчёта (`generate`), чат по документу, компиляция (LaTeX/Python/R), сессии, шаблоны, загрузки, визуализации, Scholar-поиск. |

| Canvas | `canvas/*` (1 роут) | Генерация JSON Canvas (визуальный холст в духе Obsidian Canvas) из промпта. |
| Chat | `chat/*` (1 роут) | История отдельного универсального чат-виджета (`/chat`), не путать с Agent-чатом. |

## Известные ограничения

- `src/middleware.ts` не защищает ни один из этих роутов — авторизация целиком на совести каждого отдельного `route.ts` (часть роутов вообще без проверки) — [`docs/api_reference.md`](../../../docs/api_reference.md), раздел 0.
- В проекте нет единого стандарта кодов ошибок между разделами (401 vs 403 для одинаковых случаев и т.п.) — [`docs/error_codes.md`](../../../docs/error_codes.md).
- Конкретные security-находки (дублирующий вебхук без проверки подписи, захардкоженные секреты, отсутствие проверки владения ресурсом в нескольких роутах) — [`docs/REVIEW.md`](../../../docs/REVIEW.md).
- Ни одного тестового файла на эту логику (`**/*.test.*` — 0 совпадений в репозитории).
